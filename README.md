# תיק הביטוח שלי

כלי חינמי לבדיקה עצמית של ביטוחי הבריאות בישראל.

מאפשר לאזרח למפות את הכיסויים שהוא משלם עליהם, לזהות כפל ביטוח, לראות כמה
מההוצאה מופנית להגנה מפני קטסטרופה כלכלית לעומת פיצוי ונוחות, ולייצר מכתב
ערעור על תביעה שנדחתה.

## מה יש כאן

- **מיפוי התיק** — טופס אחד שמסווג כל כיסוי ומחשב עלות חודשית, שנתית ועשורית
- **זיהוי כפל ביטוח** — בעיקר בפוליסות ניתוחים מול הביטוח המשלים של הקופה
- **מחולל מכתב ערעור** — כולל סעיף 43 לחוק חוזה הביטוח כשהוא רלוונטי
- **שאלות לסוכן** — צ'קליסט להדפסה
- **מילון מונחים** — כל מונח מקצועי בעברית פשוטה

## טכני

עמוד HTML יחיד, ללא תלויות וללא שרת. הנתונים נשמרים ב-localStorage בדפדפן
של המשתמש בלבד ואינם נשלחים לשום מקום.

## מקורות

- [הר הביטוח](https://harb.cma.gov.il/) — רשות שוק ההון, ביטוח וחיסכון
- [הגשת תלונה](https://pe.cma.gov.il/sp/sp) — היחידה לפניות הציבור
- "מתחת לבלטות" עונה 2 פרק 6, ביטוחי בריאות — כאן 11, אוגוסט 2026
